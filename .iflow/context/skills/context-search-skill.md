# Context Search Skill

## 使用场景

| 场景 | 用户意图 | 示例 |
|------|---------|------|
| 查找项目规范 | 了解协作规则 | "规范在哪"、"协作规则是什么" |
| 搜索经验沉淀 | 复用历史经验 | "之前怎么处理的"、"经验沉淀在哪" |
| 定位文档位置 | 找到具体文件 | ".iflow 里有什么"、"项目内搜索" |
| 内部知识查询 | 获取项目特有信息 | "我们的规则是"、"项目中定义的" |

## 触发条件

- 用户**明确指定**搜索范围为项目内部
- 用户需要查找项目特有的规范、经验、文档
- 用户引用项目内部概念（如 .iflow、规范、经验）

## 输入参数

- `keyword`：搜索关键词（必填）
- `path`：搜索路径（可选，默认为 `.iflow/context/`）
- `file_filter`：文件过滤（可选，如 `*.md`）

## 输出结果

- 返回匹配的文档片段
- 包含文件路径和行号
- 返回相关上下文

## 实现步骤

### 步骤 1：识别用户意图

判断用户是否需要项目内部知识

### 步骤 2：确定搜索范围

根据用户意图确定搜索路径和文件过滤条件

### 步骤 3：调用 search_file_content 工具

```bash
search_file_content --pattern="{keyword}" --path="{path}" --include="{file_filter}"
```

### 步骤 4：整理和输出

整理搜索结果，输出相关上下文

## 注意事项

1. **明确限定触发**：只有用户明确指定项目内部时才使用
2. **与 web-search-skill 配合**：复杂任务可能需要同时使用两个 skill
3. **优先级**：当用户同时需要内外部知识时，先外部后内部
