# 2026-02-28-沉淀执行问题.md

## 场景标签

- **触发条件**: 任务完成后执行沉淀步骤时
- **问题类型**: 执行错误
- **沉淀类型**: AI协作问题

---

## 问题描述

在任务完成后的沉淀步骤中，AI没有按规范执行：

1. **问用户而不是主动执行**：只问"是否需要沉淀"，而不是主动判断并执行
2. **没有按情境记忆法输出**：没有输出场景标签格式
3. **混淆沉淀类型**：把业务内容错误当成AI协作方法论

---

## 根本原因

| 问题 | 原因 |
|------|------|
| 问用户而不是执行 | 对"强制执行"理解不到位，认为需要用户确认 |
| 没有输出场景标签 | 规范理解不完整，执行时遗漏 |
| 混淆沉淀类型 | 没有用决策树区分业务vs协作 |

---

## 影响范围

- 沉淀步骤没有闭环
- 协作经验无法复用
- 用户需要额外确认

---

## 解决方案

### 沉淀执行改进

| 步骤 | 错误做法 | 正确做法 |
|------|---------|---------|
| 判断 | 问用户 | 主动判断内容类型（业务/协作） |
| 输出 | 无格式 | 按情境记忆法输出场景标签 |
| 执行 | 等待确认 | 主动执行并输出沉淀路径 |

### 沉淀类型判断决策树

```
内容是什么类型？
├─ 协作相关（方法论、沟通方式、错误预防）
│   └─ 谁使用？
│       ├─ AI使用 → .iflow/context/experience/
│       └─ 共用 → .iflow/context/rule/
│
└─ 业务相关（概念、规则、产品需求）
    └─ 谁使用？
        ├─ AI参考 → app-demand/需求/需求冷启动.md
        └─ 人类使用 → app-demand/需求/业务知识/
```

### 场景标签输出格式

```markdown
## 场景标签
- 触发条件：什么时候会遇到这个场景？
- 问题类型：这是什么类型的问题？（业务/协作/技术）
- 沉淀类型：应该沉淀到哪里？

## 场景描述
具体场景和上下文

## 解决方案
如何解决

## 沉淀路径
- 文件路径：xxx
- 更新内容：xxx
```

---

## 预防措施

1. **任务完成后**：主动判断沉淀类型，不问用户
2. **输出场景标签**：按情境记忆法格式输出
3. **用决策树判断**：业务vs协作，AI使用vs人类使用
