# 规则总入口

> **定位**: 规则体系的总入口，定义规则设计规范和分类导航

---

## 规则设计规范

定义：新增规则的设计逻辑 → 动作：遵循是什么→做什么→为什么 → 思想：确保规则简洁明了，易于理解和执行

**案例**：在规则定义中添加详细示例是错误做法。规则定义应只保留一行，详细示例应放在规则详解目录中。

``` markdown
❌ 错误：在规则定义中添加详细示例
### 07. Markdown格式
定义：... → 动作：... → 思想：...
正确格式：` ``` text `
错误格式：` ```text `

✅ 正确：规则定义只保留一行，详解放目录
RULE_SPEC.md: 定义：... → 动作：... → 思想：...
07-markdown-format/markdown-format.md: 详细示例、案例、最佳实践
```
