# 五种 Skill 执行模式

> **定位**: 根据场景选择合适的 Skill 执行方式
> **L2 引用**: @.iflow/ecosystem/skills/SKILLS_SPEC.md

---

## 定义

根据场景选择合适的 Skill 执行方式。

## 模式对比

| 模式 | 核心机制 | LLM 角色 | 适用场景 |
|------|---------|---------|---------|
| **纯 Prompt 注入** | 仅注入 body 到 system prompt | 遵循者 | 教规范/风格 |
| **脚本执行** | 预制脚本 + skill_run | 调用者 | 操作文件格式 |
| **库调用** | LLM 写代码 import 库 | 开发者 | 灵活组合 API |
| **渐进加载** | 路由表 + 按需加载文档 | 选择者 | 知识量大 |
| **编排型** | 多阶段工作流 + 子 Agent | 协调者 | 复杂流程 |

## 模式光谱

```
轻量 ◄────────────────────────────────────► 重量
纯Prompt  渐进加载  库调用  脚本执行  编排型
```

## 选择指南

| 你的场景 | 推荐模式 | 你需要做的 |
|---------|---------|-----------|
| 教 LLM 遵循某种规范/风格 | 纯 Prompt 注入 | 写好 SKILL.md |
| 需要 LLM 操作特定文件格式 | 脚本执行 | 写预制脚本 + 使用说明 |
| 需要 LLM 灵活组合 API | 库调用 | 写库 + API 文档 |
| 知识量大，不同任务需要不同文档 | 渐进加载 | 路由表 + 详细文档 |
| 需要 LLM 执行复杂多步骤工作流 | 编排型 | 流水线 + 工具链 |
