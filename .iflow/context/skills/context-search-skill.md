# Context Search Skill

## 技能描述
上下文搜索技能：搜索项目文档，用于查找项目相关的信息和经验

## 触发条件
- 需要查找项目文档中的信息
- 需要查找项目相关的经验和最佳实践
- 需要查找项目相关的概念和定义

## 输入参数
- `keyword`：搜索关键词（必填）
- `path`：搜索路径（可选，默认为 `.iflow/context/`）
- `file_filter`：文件过滤（可选，如 `*.md`）

## 输出结果
- 返回匹配的文档片段
- 包含文件路径和行号
- 返回相关上下文

## 实现步骤

### 步骤 1：接收输入参数
接收用户提供的搜索关键词、搜索路径和文件过滤条件

### 步骤 2：使用 search_file_content 工具搜索
调用 `search_file_content` 工具，在指定路径下搜索关键词

``` bash
search_file_content --pattern="{keyword}" --path="{path}" --include="{file_filter}"
```

### 步骤 3：分析搜索结果
分析搜索结果，提取相关的文档片段和上下文

### 步骤 4：返回结果
返回匹配的文档片段，包括文件路径和行号

## 注意事项

1. **搜索关键词要准确**：搜索关键词应该准确反映需要查找的内容
2. **搜索路径要正确**：搜索路径应该指向正确的目录
3. **文件过滤要合理**：文件过滤应该只搜索相关的文件类型
4. **结果要完整**：返回的结果应该包含足够的上下文信息
