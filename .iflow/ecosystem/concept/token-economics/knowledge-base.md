# 知识基座（Knowledge Base）

> **定位**: 让 AI 越用越懂业务的团队经验实践
> **L2 引用**: @.iflow/ecosystem/concept/ai-collaboration/deposition.md（沉淀机制）

---

## 核心要点（必须记住）

- **核心问题**：如何把超级个体变成超级团队？
- **信号驱动沉淀**：只捕获"踩坑现场"，不是全量记忆压缩
- **云端共享**：团队共享知识库，跨仓库、跨用户
- **知识闭环**：一个人踩坑 → 自动沉淀 → 全团队受益
- **与个人记忆的区别**：Cursor Memory 是个人偏好，知识基座是团队经验

---

## 核心问题

**超级个体的困境**：
- 同样的问题，有人5分钟解决，有人花2小时
- 经验锁在个人本地配置里，无法惠及团队
- Cursor Memory 记住的是"个人偏好"，不是"团队知识"

**目标**：把超级个体变成超级团队

---

## 个人记忆 vs 知识基座

| 维度 | Cursor Memory / Claude Memory | 知识基座 |
|------|------------------------------|---------|
| **存储位置** | 本地存储，跟着个人设备走 | 云端存储，团队共享 |
| **作用范围** | 单仓库、单用户 | 跨仓库、跨用户、按业务域隔离 |
| **沉淀机制** | 全量记忆压缩（把对话摘要存下来）| 信号驱动提取（只捕获"踩坑现场"）|
| **知识质量** | 混杂大量无价值对话 | 聚焦真正有价值的踩坑经验 |

---

## 信号驱动沉淀

**核心思想**：不依赖手动维护文档，从日常研发活动中自动捕获有价值的知识。

### 信号类型

| 信号类型 | 触发时机 | 沉淀内容 |
|---------|---------|---------|
| **踩坑信号** | 执行遇到错误 | 错误原因 + 解决方案 |
| **最佳实践信号** | 执行成功后反思 | 高效模式 + 复用方法 |
| **新发现信号** | 执行中发现 | 业务规则 + 隐藏依赖 |

### 沉淀格式

```text
## 场景标签
- 触发条件：什么时候会遇到这个场景？
- 问题类型：踩坑/最佳实践/新发现

## 场景描述
描述具体的业务场景和上下文

## 解决方案
描述如何解决这个问题

## 关联经验
链接到相关的经验文档
```

## 知识闭环

```
同学 A 踩坑并解决
       │
       ▼
┌──────────────────────────────┐
│ 信号触发：错误日志/调试输出    │
└──────────────────────────────┘
       │
       ▼
┌──────────────────────────────┐
│ 自动沉淀：提取场景+解决方案   │
└──────────────────────────────┘
       │
       ▼
┌──────────────────────────────┐
│ 云端同步：写入团队知识库      │
└──────────────────────────────┘
       │
       ▼
同学 B 遇到同样问题 → AI 自动提示
```

## AI 执行检查

| 检查项 | 合格标准 | 不合格示例 |
|-------|---------|-----------|
| **信号识别** | 识别踩坑/最佳实践/新发现信号 | 无信号触发机制 |
| **场景标签** | 有触发条件+问题类型+解决方案 | 只有描述无标签 |
| **云端同步** | 写入团队共享位置 | 只存本地 |
