# Web Search Skill

## 技能描述
网络搜索技能：搜索网络上的信息，用于查找概念、技术细节、最佳实践等

## 触发条件
- 需要查找项目文档中没有的信息
- 需要查找技术概念的定义和解释
- 需要查找最新的技术趋势和实践

## 输入参数
- `query`：搜索查询（必填）
- `num`：返回结果数量（可选，默认为 10）

## 输出结果
- 返回搜索结果的摘要
- 包含标题、链接、日期

## 实现步骤

### 步骤 1：接收输入参数
接收用户提供的搜索查询和返回结果数量

### 步骤 2：使用 web_search 工具搜索
调用 `web_search` 工具，搜索网络上的信息

``` bash
web_search --query="{query}" --num={num}
```

### 步骤 3：分析搜索结果
分析搜索结果，提取相关的信息

### 步骤 4：返回结果
返回搜索结果的摘要，包括标题、链接、日期

## 注意事项

1. **搜索查询要准确**：搜索查询应该准确反映需要查找的内容
2. **结果数量要合理**：返回的结果数量应该合理，避免过多或过少
3. **结果要筛选**：应该筛选出最相关的结果
4. **链接要有效**：确保返回的链接是有效的
