# AI主动性不足问题

## 场景标签
- **触发条件**：修改多章节文档时、发现潜在问题时
- **问题类型**：AI只响应人类指出的问题，缺乏主动观察和提出

## 场景描述

在修改 `collaboration-method.md` 添加笛卡尔方法论章节时，AI出现以下问题：

1. **章节排序遗漏**：AI只考虑了添加新章节，没有质疑"现有章节顺序是否合理"
2. **方法关系形式化**：AI创建了"层次结构图"，但只是分组导航，没有让章节真正有机联系
3. **归因错误**：AI把"全面检查"只归功于笛卡尔，忽略了乔哈里窗、PDCA等方法也能保证全面
4. **被动等待**：所有问题都是等用户指出后才发现

## 根本原因

| 原因 | 说明 |
|------|------|
| **任务束缚** | 被"添加章节"任务束缚，没有用方法论指导自己的行为 |
| **自指缺失** | 在添加"笛卡尔方法论"时，没有执行笛卡尔方法论 |
| **归因简单化** | 把复杂能力只归功于单一方法 |
| **形式主义** | 创建了导航结构，但内容没有真正改变 |

## 解决方案

### 1. 增加AI主动提出规范

**触发条件**：修改多章节文档时

**AI必须输出**：
``` text
## 整体结构检查

在修改文档前，我观察到以下问题：

1. **内容完整性**：[描述]
2. **关系正确性**：[描述]
3. **顺序合理性**：[描述]

是否需要一并调整？
```

### 2. 禁止行为

- 等待人类指出问题
- 只关注局部，忽略整体
- 假设现有结构合理，不质疑

### 3. 方法归因正确化

多个方法可以保证同一能力：

| 能力 | 相关方法 |
|------|---------|
| **全面检查** | 笛卡尔全面检查、乔哈里窗（识别未知区）、PDCA的Check、联动检查 |
| **分解问题** | 笛卡尔分解原则、待办列表管理 |
| **质疑验证** | 笛卡尔怀疑精神、苏格拉底本体提问 |

## 验证结果

已更新 `collaboration-method.md`：
- 增加"AI主动提出规范"
- 每个章节增加"方法关系"说明
- 章节按层次重新排序
