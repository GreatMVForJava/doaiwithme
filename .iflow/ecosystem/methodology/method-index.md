# 方法索引

> **定位**: 执行层，AI快速查找方法
> **适用场景**: AI需要选择合适的协作方法

---

## 方法-流程映射表

| 流程阶段 | 方法 | 行为规则 |
|---------|------|---------|
| 预检 | 怀疑+分解 | 理解有歧义时输出"我理解...是否正确？"；多文件任务先拆分再逐个执行 |
| 确认 | 乔哈里窗 | 识别盲点区（人类知道AI不知道）→ 主动提问；识别隐藏区（AI知道人类没表达）→ 主动暴露 |
| 规划 | 联动检查 | 修改前搜索引用、评估影响、同步关联项 |
| 规划 | 渐进式披露 | 按需加载内容，不一次读取全部 |
| 执行 | PDCA循环 | 逐项跟踪、主动汇报，遇到未知问题循环迭代 |
| 执行 | 删除前评估 | 删除内容前必须评估重要性、检查依赖、设计替代方案 |
| 自检 | 完整检查 | 规则检查表逐条确认，自指检查：我是否真正执行了我说做的？ |
| 沉淀 | 情境记忆法 | 场景标签 + 场景描述 + 解决方案，固化后删除 |

---

## 触发条件索引

| 触发场景 | 行为 |
|---------|------|
| 规则/需求理解有歧义 | 输出"我理解...是否正确？"，等待确认 |
| 任务涉及多个文件 | 先拆分任务列表，再逐个执行 |
| 遇到未知问题 | PDCA循环：计划→执行→检查→调整 |
| 修改代码/文档 | 联动检查：搜索引用→评估影响→同步关联项 |
| 经验沉淀 | 场景标签 + 场景描述 + 解决方案 |
| 协作开始时 | 识别乔哈里窗区域，扩大开放区 |
