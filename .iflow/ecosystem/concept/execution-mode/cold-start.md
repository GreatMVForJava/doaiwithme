# 冷启动（Cold Start）

> **定位**: AI 从零理解项目
> **L2 引用**: @.iflow/ecosystem/experience/cold-start.md

---

## 定义

AI 在没有上下文的情况下开始工作，需要从零理解项目结构、业务逻辑、技术栈、规范约束。

## 表现

| 表现 | 说明 |
|------|------|
| **重复询问** | 每次都要问"项目结构是什么" |
| **规范不符** | 生成的代码不符合项目规范 |
| **经验丢失** | 无法复用之前的解决方案 |
| **理解偏差** | 对需求的理解与预期不符 |

## 解决方案

四层防御体系：
1. Level 0：Cache 状态层
2. Level 1：项目级冷启动
3. Level 2：需求级冷启动
4. Level 3：任务级执行清单
